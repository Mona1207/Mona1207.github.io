01 · OVERVIEW

实验概览：这次实验到底在练什么

本实验是 Java 入门后的第一次综合训练：把「变量与常量、数据类型、键盘输入、运算、选择结构」这些零散语法，组织成两个能处理非法输入、能给出格式化结果的完整程序。

A实验目的

  • 熟悉 Java 程序的基本结构，掌握 javac 编译、java 运行的完整流程
  • 掌握变量、final 常量的定义与「见名知意」的命名规范
  • 掌握 int / double / boolean / String 等类型及类型转换
  • 熟练使用 Scanner 键盘输入与 printf 格式化输出
  • 熟练运用 if / if-else / switch 选择结构与逻辑运算符解决分支问题

B实验环境

  • 操作系统：Windows 10 / 11（macOS、Linux 同理）
  • JDK：JDK 17（LTS）或课程指定版本，命令行 javac / java 可用
  • 开发工具：IntelliJ IDEA / Eclipse，或其他能编译运行 Java 的工具（如 VS Code + Java 扩展包）
验证环境：命令行执行 javac -version 与 java -version 能打印版本号，即说明 JDK 安装并配置成功。
TASK 01 · 顺序 + 单分支

课程总评成绩计算器

class GradeCalculator

输入姓名、学号和三项成绩（平时 10%、实验 30%、期末 60%），校验 0~100 合法性后计算总评，保留两位小数，并按分数段输出等级。

训练点：常量、Scanner 混合读取、|| 合法性判断、if-else if 链、printf

TASK 02 · 多级嵌套判断

三角形类型分析器

class TriangleAnalyzer

输入三条 1~1000 的整数边，依次完成范围校验、构成判断、类型分类、直角判定，最后计算周长与海伦公式面积。

训练点：&& 组合条件、判断顺序、boolean、Math.sqrt、整数除法陷阱
