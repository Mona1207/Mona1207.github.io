## 平板布局

700px及以上使用紧凑的视口布局，首页、设置和主要目录避免整页长滚动，模块字号及留白均缩小。设置卡片两列；知识树、知识点练习、全书框架共享“章节树 → 小节 → 并排知识点”的布局，章节与知识点均分页。知识点选择仍按单点启动独立练习，保持考法去重与先修条件。

知识点讲解按定义、条件推导、具体例子分段阅读，考法列表及较长推导也可切页。教材目录、原题、错题、笔记列表、学习路径与报告采用分页或双栏。任意长度的用户笔记、特别长的公式和复杂原题仍允许在内容栏内滚动，以保持可读字号和完整内容；不承诺所有题型在所有屏幕上均完全无需滚动。

## 手写演算与自评

答题前右侧是手写草稿板；答题后默认显示解析，可切回原草稿继续演算。支持压感笔、默认忽略手指输入、可选手指书写、橡皮、三种笔色、撤销/重做、可撤销清空、方格开关、放大与PNG导出。笔迹采用归一化向量保存，旋转和区域尺寸变化时重绘；按教材和题号保存在本机，离开题目和正在书写时也保存已收集的笔迹。常驻笔迹缓存为位图，仅重绘当前笔画以减少连续书写开销。

手写草稿用于演算，不做手写答案识别，也不自动改变掌握度。它与文字笔记及可判题记录分开，当前教材JSON备份不含手写草稿，可在画板导出PNG。

自评压缩为一行三项：独立正确、部分正确、错误。答错或使用过辅助时，独立正确不可选；客观判题不会被自评覆盖。旧版五种评价的历史值保留，仅在界面映射显示；本书待核验原题自评仍不自动计入掌握度。
