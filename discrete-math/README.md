## 重建与验证

先保留原有v14种子与v13题库，再依次运行：

```sh
python3 discrete-math/scripts/build-textbooks-v15.py
python3 discrete-math/scripts/scan-original-items-v15.py --ocr-directory /path/to/ocr
python3 discrete-math/scripts/enrich-lessons-v15.py
python3 discrete-math/scripts/build-ui-v15.py
node discrete-math/scripts/test-v15.mjs
node discrete-math/scripts/test-ui-flow-v15.mjs
node discrete-math/scripts/test-originals-v15.mjs
```

扫描器输入为每本书的逐页Tesseract TSV：`DM2T/001.tsv`…`414.tsv`、`LA7/001.tsv`…`176.tsv`、`PS3/001.tsv`…`268.tsv`。处理时保留TSV行坐标，中文模型145DPI；输入PDF与完整OCR正文不进入公开仓库。少数经原页抽查的题号更正在扫描脚本中明示。
