## 原书读取稳定性修复（reader v19.1）

本次优先修复教材与习题原页读取，未发布进行中的习题 OCR 和答题右栏改版。

- 教材清单内置到读取器；分段文件完整下载后检查长度、PDF 标识和 SHA-256，再交给 PDF.js，避免多段 Range 请求及不完整内容。
- 下载（包括响应体）有超时与一次自动重试，解析和绘制也有超时；失败不保留为无法恢复的缓存。
- 已校验的教材分段尽力保存到浏览器 CacheStorage；缓存不可用时仍可联网读取。完整备份的学习记录、图片与手写草稿不变。
- 活跃页面持有文档引用，绘制完成或取消后才释放；仅回收闲置教材文档。快速翻页时旧结果不能覆盖新页。
- 每次绘制使用独立临时画布，成功后才更新可见画布；加载及错误状态不卸载目标画布，重试可恢复。
- PDF 主线程与 Worker 都加入 `Promise.withResolvers` 兼容处理。保留原有本机 PDF 备用读取。

## v18 学习流程

课本例题与课后习题为两个同级入口，主要学习流程只使用教材题目。此前生成的可判题练习退出主界面，历史记录保留在备份中。

所有前置条件取消锁定，学习引擎也统一返回可访问。知识点只标注可跳转的前置参考，不再展示学习路径页面、锁定门槛或旧独立练习面板。旧学习路径链接转到知识树，旧练习链接转到对应课本题列表。

知识树完整章节和小节在模块内连续滚动；知识点并排显示，不分页。点击知识点直接展示相关题号，题目旁可跳转知识讲解；讲解中保留前置参考。列表筛选、知识树章节与滚动位置会保留，下一题/上一题沿用当前题目范围并替换题目历史，返回时回到来源列表。

题目支持星标。知识点、题目模块及学习报告的电量条按“查看答案并完成自评”的题目数统计；不将浏览、星标或重复自评累加成新完成量，也不将该进度称为客观掌握度。具有逐题索引的完整习题组不重复计入进度分母。

700px以上答题页为题目、草稿、答案解析自评三栏。拖动两条分隔线可调整宽度；每栏有最小宽度约束，并按教材保留偏好。分隔线支持方向键微调、Shift加速、Home/双击重置。拖拽事件仅绑定分隔线，不绑定手写画布。小于700px时三个分区切换显示，草稿保持挂载与自动保存。

例题星标、自评、文字思路与进度沿用现有完整备份格式，与图片笔记和向量草稿一起恢复。旧版记录、笔记、收藏与备份保留。

## 图片笔记与完整备份

习题或例题右侧 → 图片笔记，可导入PNG/JPG/WebP/GIF，亦可粘贴、拖入，图片原文件内嵌在本机记录中。每张图片绑定当前教材和题号，可填写说明、放大、下载。删除进入回收区，可以恢复。单张最大20MB。手写草稿可直接“存为笔记”。

“下载备份”及设置 → 学习规则与备份 → 备份恢复，下载同一份当前教材完整JSON：学习进度、作答、自评、文字笔记、图片原文件、手写向量草稿与原题记录均包含在内。恢复不依赖原设备的图片路径，也无需逐张重新导入。

恢复流程：选文件 → 校验教材与完整性 → 预览条目数量 → 确认恢复。恢复前保留完整副本，可另行下载。图片与笔迹恢复使用持久日志处理页面中断，重新打开时继续；其他教材记录保留。旧版学习备份仍可导入，并保留当前图片及草稿。

自动保存属于当前浏览器本机存储，不自动同步其他设备。更换设备需下载并导入完整备份。
