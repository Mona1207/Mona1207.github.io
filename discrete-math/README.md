设置 → 我的教材切换。离散数学继续使用原 IndexedDB `zhixu-pages-v2`，另外两门课分别使用 `zhixu-pages-v14-LA7`、`zhixu-pages-v14-PS3`。每本教材的作答、自评、错题、笔记和备份分别保存。切换教材前已填写草稿会保留；备份恢复先校验，再预览确认；拒绝将另一教材的备份恢复到当前教材。

按考法去重继续沿用 v13 引擎。仅改数值、名字、顺序的练习不会被当成新考法堆叠。教材矩阵的多个同类计算共用考法分组。客观判题与自评分开，使用辅助或答错不能在作答页选择“独立正确”。
