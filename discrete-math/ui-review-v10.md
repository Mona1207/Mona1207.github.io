# 知序 v10：以知识点为中心

## 实际页面诊断

2026-10-13 对线上首页、知识树及「命题与真值」详情进行真实点击与截图检查：

- 知识点详情首屏的进度卡过大，正文被推到下方；页面标题重复、按钮「学习该知识」实际上直接开始答题，动作含义不清楚。
- 讲解拆成八段，其中「直观理解 / 使用方法」「常见错误 / 易混淆点」内容相同；通用条件说明与具体概念无关。
- 练习入口同时提供章节、小节、知识点三种范围，同一用户任务有多套入口。
- 选题器先排不同 family，再把同一 family 的变式接回队列，最终补足 10 题。只按 ID 记录历史，换数值的题仍反复出现。
- 人工题与生成题之间、名称不同但考法相同的生成模板之间，也存在重复。

## 界面与交互

- 首页只推荐知识点，提供继续练习、知识点目录、错题与笔记。
- 知识树保留章节分组及树状连线，章节行只展开/收起，叶子才进入学习。
- 知识点详情采用主阅读栏 + 练习侧栏；手机依阅读顺序单栏排列。定义、例子、易错点各出现一次；去除重复文字和通用占位段落。
- 练习清单按需展开；前置知识在同页直接跳转；练习结束返回当前知识点。
- 蕴涵知识点加入 p、q 真值切换演示，立即呈现结果，不写入成绩。
- 统一字级、行宽、边框、圆角、间距；减少大面积色块，使用中性灰白与少量鼠尾草绿；保留深色模式、键盘焦点和减少动态效果偏好。
- 学习目录、题库、学习路径统一采用知识点入口。章节旧链接落到知识点目录，不再启动章节练习。

设计参考：[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)：明确层级，常用动作持续可见，辅助信息按需展开。未宣称访问 Mobbin 付费案例或复制其页面。

## 选题与证据规则

- 原 1,840 道已核验题逐一映射到经过审查的考法分组；保留全部原题 ID、题目内容与历史引用。
- 合并只改数字/变量/真值的变式、手工与生成题的同类考法，以及跨知识点的同类模板。
- 新增三道不同能力的题：必要条件符号化、避免变量捕获、合法顶点着色验证。
- 当前 1,843 道已核验题对应 146 种独立考法。
- 常规练习：每种考法一道；全局历史中已作答的考法排除；不足目标数量不补重复题。
- 错题及到期复习由用户主动进入，同样每种考法最多一道。
- 置信度每种考法只使用最近一次评价，重复变式不再累加证据。同一已审核考法可在关联知识点间复用证据。先验不确定性随独立考法证据补足而消退，避免只有两种考法的知识点永远卡在 71%；独立考法数量与间隔复测的掌握条件保留。
- 不改写或删除旧作答。旧章节会话保留在历史，不再作为继续学习入口。旧知识点会话恢复时过滤未作答的重复变式；已提交题保留用于评价。
- 内容不足或考法用尽时明确显示空状态，不伪造题量或降低掌握门槛。掌握度可能因纠正历史重复证据而调整。
- 新上传的自定义题采用题族与数值归一化后备规则；本次逐题审查范围为内置题库，并非宣称自动语义算法能识别所有未来题目。

## 维护与验证

源码组件在 `scripts/ui-v10-components.js`；工作线程选题逻辑在 `scripts/worker-v10-methods.js`；考法映射来源在 `scripts/build-practice-groups-v10.py`。现有部署仅提供编译产物，因此以可重复构建的补丁维护，保留原 bundle 供回滚。

```sh
python discrete-math/scripts/build-practice-groups-v10.py
python discrete-math/scripts/build-ui-v10.py
node --check discrete-math/assets/app-ui-v10.js
node discrete-math/scripts/test-ui-v10.mjs
```

自动验证覆盖全部 46 个知识点的题量、单轮去重、跨会话/跨知识点历史排除、不凑数、前置限制、旧记录保留、恢复会话、主动错题复习，以及新增题的独立考法数量。
