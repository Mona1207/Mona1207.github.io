## 实际体验诊断

实测路径：首页 → 开始练习 → 选择 B → 提交 → 下一题 → 自评弹层 → 关闭 → 返回首页；知识树 → 展开第 7 章；设置页。

| 优先级 | 页面上实际观察到的问题 | 用户影响 | 此次落地 |
|---|---|---|---|
| 高 | 约 1350px 宽屏上，首页、知识树、设置仍限制为 430px | 两边大幅空置；“命题逻辑基本概念”的最后一字单独换行 | 首页 1060px 容器、桌面两列；树 840px、设置 760px；手机单列 |

| 中 | 树状列表字体粗、状态标签占比大，章节名在窄栏断行 | 扫描长章节困难 | 扩宽树，细连线、轻量状态、44px 展开触控区 |
| 中 | 进度更新藏在“学习辅助”中 | 无法即时理解本次练习价值 | 自评后原地显示真实掌握度变化 |

## 设计规格

暖灰白 #F7F8F5、白纸 #FFFFFF、墨绿 #26735B、正文 #202D28、次要文字 #637269。主题使用 CSS 变量，深色模式同步覆盖。16–24px 圆角，按钮多为 44–50px，正文 15–17px；题干 21–23px。保留既有兔子与书本素材，不再多处摆放太阳与剪贴板；移除对应图像节点，避免继续下载近 1MB 的太阳 PNG。

动效用于选中、展开、批改、保存反馈；没有自动漂浮和循环动画。支持 prefers-reduced-motion、focus-visible 与当前页 ARIA 标识。

首页保留三个原导航，学习入口和真实进度；知识树仅呈现树；练习保留先独立作答后解析；设置保留全部原有功能。

## 实现边界

本仓库只有当前站点的生产资产，未含匹配的 TSX 工程。新增 `assets/ui-v9.css` 和 `assets/app-ui-v9.js`；`scripts/build-ui-v9.py` 对原 V8 入口做有唯一锚点检查的可重复补丁。原 V8 文件保留，可回退入口。
